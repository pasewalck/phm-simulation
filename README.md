# **Ph**ysics & **M**aths Simulations

A collection of physics and math simulations I created and plan to create to better understand the concepts I learn about in my physics bachelor at TU Berlin.

It all really started when I watched a video by 3Blue1Brown and thought to myself that it'd be fun to recreate something similar and make it intractable.

After doing some research on JavaScript libraries that would work well, I quickly ended up using [p5.js](https://p5js.org/). I ended up setting somewhat universal code for rendering different types of plots with animations.

So far I have gotten around to writing simulation code for:

- [Fourier-Series](https://github.com/pasewalck/phm-simulation/tree/main/projects/fourier)
- [Taylor-Series](https://github.com/pasewalck/phm-simulation/tree/main/projects/taylor)
- [Laplace operation](https://github.com/pasewalck/phm-simulation/tree/main/projects/laplace)

See a [demo here](https://pasewalck.github.io/phm-simulation-dist/)!
At the time being, the UI is in German, but if I ever get to it, I will translate it.
